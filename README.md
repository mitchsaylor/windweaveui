# WindWeave UI

Extends your project's TailwindCSS config with theme variables that includes a wider range of text, size, and color options for building more consistent visual layouts. Also includes a set of UI-related components for use in Svelte projects.

Requires [TailwindCSS](https://tailwindcss.com/) v4.
Components require [Svelte](https://svelte.dev/) 5.

## Usage

Install the package

```sh
npm i -D windweave
```
